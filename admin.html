🔑 GitHub Setup

Connect your GitHub repository to publish posts and upload images directly from this dashboard.

Create one at: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)

📖 How to Get Your Token

  1. Go to github.com/settings/tokens
  2. Click "Generate new token (classic)"
  3. Give it a name like "Blog Admin"
  4. Check the "repo" scope (full control of private repositories)
  5. Click "Generate token"
  6. Copy the token immediately — you can't see it again!
  7. Paste it above and click "Save Credentials"
